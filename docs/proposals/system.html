Kept

  • Automation transparency. When it last ran, when it runs next, how old the data is.
  • The ability to run the scan by hand, unchanged — it still triggers the same job.
  • The fetch error list, which was a red line at the bottom of the Scan page.
  • The 10-minute cache note, so a push that has not appeared yet does not read as a failure.

Changed

  • Operational controls have a home. Run scan now leaves the masthead, where it sat next to the product name on every page.
  • Stale is loud. Three numbers at the top say last run, next run, and errors, and a stale scan turns the first one red with a banner.
  • Each check says what it means when it fails, instead of showing a count and leaving you to guess.
  • Quote coverage is a status check now. How many open calls carry a real bid/ask versus a model price is a health signal and was never surfaced.
  • A quiet day and a broken job cannot look the same. That was the whole reason this page exists.
